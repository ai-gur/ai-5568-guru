# רשימת בדיקה לפני פרסום — אתר או יישום אינטרנט

עברו על הרשימה לפני העלאה לאוויר. כל שורה מפנה לקריטריון בטופס הבדיקה הרשמי.

## מבנה ושפה

- [ ] `<html lang="he" dir="rtl">` (3.1.1 + תוספת ישראלית)
- [ ] כותרת `<title>` ייחודית שמתארת את העמוד, החלק הספציפי ראשון (2.4.2)
- [ ] כותרת `<h1>` אחת בדיוק בעמוד (2.4.10)
- [ ] היררכיית כותרות רציפה — אין דילוג מ-h2 ל-h4 (1.3.1)
- [ ] אין טקסט שמעוצב ככותרת אך אינו h1-h6 (1.3.1)
- [ ] רשימות ממומשות ב-`<ul>`/`<ol>`/`<dl>`, לא בתווי תבליט מוקלדים (1.3.1)
- [ ] אזורי העמוד מוגדרים ב-`header`/`nav`/`main`/`footer` (1.3.1)
- [ ] קטעים בשפה זרה מסומנים ב-`lang` (3.1.2)
- [ ] אין תגיות עיצוביות — `font`, `center`, `bgcolor`, `align` (1.3.1)

## עברית ו-RTL

- [ ] מספרי טלפון, ת"ז, מספרי הזמנה ודוא"ל עטופים ב-`dir="ltr"` או `<bdi>`
- [ ] CSS משתמש במאפיינים לוגיים — `inset-inline-start`, לא `left`
- [ ] אייקונים כיווניים (חצים) ממוראים ב-RTL
- [ ] כל השמות הנגישים, התוויות והודעות השגיאה בעברית (תוספת ישראלית)

## תמונות ומדיה

- [ ] לכל תמונה אינפורמטיבית `alt` שמתאר את המידע (1.1.1)
- [ ] תמונות דקורטיביות עם `alt=""` (1.1.1)
- [ ] תמונה בתוך קישור — ה-`alt` מתאר את היעד, לא את התמונה (1.1.1)
- [ ] אין טקסט "צרוב" בתוך תמונה — באנרים, כרזות, צילומי מסך (1.4.5)
- [ ] לווידאו עם קול יש `<track kind="captions" srclang="he">` וכתוביות שנבדקו (1.2.2)
- [ ] לווידאו יש תמלול או תיאור טקסטואלי בעמוד (1.2.1, 1.2.3)
- [ ] לתרשימים וגרפים יש תיאור מלא בטקסט, לא רק `alt` קצר
- [ ] אין אודיו שמתנגן אוטומטית — או שיש פקד עצירה בתחילת העמוד (1.4.2)

## טפסים

- [ ] לכל שדה `<label for>` גלוי ומשויך (3.3.2)
- [ ] `placeholder` משמש כדוגמה בלבד, לא כתווית (3.3.2)
- [ ] שדות חובה מסומנים במילה "חובה", לא בכוכבית אדומה בלבד (1.4.1)
- [ ] הודעות שגיאה בעברית, משויכות ב-`aria-describedby`, עם `role="alert"` (3.3.1)
- [ ] הודעת השגיאה אומרת מה לתקן, לא רק "שגיאה" (3.3.3)
- [ ] קבוצות רדיו/צ'קבוקס ב-`<fieldset>` עם `<legend>` (1.3.1)
- [ ] שינוי ערך בשדה אינו מנווט או שולח טופס אוטומטית (3.2.2)
- [ ] בטופס עם השלכות משפטיות/כספיות — יש מסך אישור או אפשרות ביטול (3.3.4)

## מקלדת ומיקוד

- [ ] כל פעולה ניתנת לביצוע במקלדת בלבד (2.1.1)
- [ ] אין מלכודות מקלדת — אפשר לצאת מכל רכיב ב-Tab (2.1.2)
- [ ] סדר המיקוד תואם את הסדר החזותי (2.4.3)
- [ ] לכל רכיב ממוקד יש אינדיקטור חזותי ברור — אין `outline: none` ללא חלופה (2.4.7)
- [ ] אין `tabindex` חיובי (2.4.3)
- [ ] קישור דילוג לתוכן הראשי, ראשון בסדר המיקוד, נגלה בפוקוס (2.4.1)
- [ ] יעד הדילוג נושא `id` ו-`tabindex="-1"` (2.4.1)
- [ ] קבלת פוקוס אינה משנה הקשר (3.2.1)

## תצוגה

- [ ] ניגודיות 4.5:1 לטקסט רגיל, 3:1 לטקסט גדול (1.4.3)
- [ ] הגדלת טקסט ל-200% — אין חיתוך ואין אובדן תוכן (1.4.4)
- [ ] תגית viewport אינה כוללת `user-scalable=no` או `maximum-scale=1` (1.4.4)
- [ ] אין מידע שמועבר בצבע בלבד (1.4.1)
- [ ] קישורים בתוך פסקה מובחנים בקו תחתון או ביחס 3:1 + שינוי ב-hover/focus (1.4.1)
- [ ] אין הוראות שמסתמכות על צורה, מיקום או צליל בלבד (1.3.3)

## תנועה וזמן

- [ ] אין `<meta http-equiv="refresh">` (2.2.1)

- [ ] סדר פריטי הניווט זהה בכל העמודים (3.2.3)
- [ ] רכיבים חוזרים נושאים אותו שם נגיש בכל האתר (3.2.4)
