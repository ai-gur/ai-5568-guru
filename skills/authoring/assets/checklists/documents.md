# רשימת בדיקה לפני פרסום — מסמכים להורדה (חלק 2)

חלה על מסמכי PDF, Word, PowerPoint, Excel וטקסט שמתפרסמים להורדה.
טפסים אינטראקטיביים לא נכללים — עליהם חל **חלק 1**.

## כללי — כל סוגי המסמכים

- [ ] למסמך יש כותרת (Title) בעלת משמעות, או לפחות שם קובץ מתאר (2.4.2)
- [ ] שם הקובץ אינו `doc1`, `scan_0012`, `final_v3` (2.4.2)
- [ ] שפת המסמך מוגדרת (עברית)
- [ ] קטעים בשפה זרה מסומנים בשפתם
- [ ] טקסט המוצג ככותרת מסומן בסגנון כותרת סמנטי (1.3.1)
- [ ] במסמך עם יותר מרמת כותרת אחת — ההיררכיה רציפה (1.3.1)
- [ ] רשימות נוצרו ברשימה אוטומטית, או במספור ידני רציף והיררכי (1.3.1)
- [ ] לכל תמונה נושאת מידע יש טקסט חלופי (1.1.1)
- [ ] תמונות דקורטיביות מסומנות ככאלה (1.1.1)
- [ ] אין קבצים סרוקים (1.4.5) — **חלק 2 אוסר זאת במפורש**
- [ ] אין צילומי מסך של טקסט או של טבלאות (1.4.5)
- [ ] סדר הקריאה תואם את סדר התצוגה (1.3.2)
- [ ] אין מידע שמועבר בצבע בלבד (1.4.1)
- [ ] אין הפניות מסוג "ראה בטבלה מימין" — הפנו לפי מספר או שם (1.3.3)
- [ ] תכלית כל קישור ברורה מהטקסט או מההקשר (2.4.4)
- [ ] כותרות ותוויות מתארות את הנושא, ופסקאות אינן מסומנות ככותרת (2.4.6)
- [ ] למידע מורכב — גרפים, נוסחאות, טבלאות מרובות שכבות — יש תיאור טקסטואלי (סעיף 6)

## ניגודיות — ספי חלק 2, שונים מהאינטרנט

- [ ] טקסט הגוף עומד ביחס הנדרש לפי גודלו
- [ ] אין טקסט אפור בהיר על רקע לבן
- [ ] אין טקסט על גבי תמונה או מילוי צבעוני ללא בדיקת ניגודיות

## Word

- [ ] נעשה שימוש בסגנונות "כותרת 1/2/3", לא בהדגשה והגדלה ידנית
- [ ] חלונית הניווט (View → Navigation Pane) מציגה את המבנה הנכון
- [ ] לטבלאות מסומנת שורת כותרת (Table Layout → Repeat Header Rows)
- [ ] אין תאים ממוזגים
- [ ] אין תיבות טקסט צפות
- [ ] הורץ Review → Check Accessibility

## PowerPoint

- [ ] לכל שקופית יש כותרת, והכותרות שונות זו מזו
- [ ] הכותרות נמצאות ב-placeholder של הפריסה, לא בתיבת טקסט חופשית
- [ ] Outline View מציג את כל הכותרות
- [ ] סדר הקריאה נכון בחלונית הבחירה (נקרא מלמטה למעלה)
- [ ] לתרשימים יש תיאור מלא, לא רק שם

## Excel

- [ ] לכל גיליון שם בעל משמעות — לא "Sheet1"
- [ ] הוגדרה טבלה עם שורת כותרת (Insert → Table)
- [ ] הנתונים מתחילים ב-A1, ללא שורות ריקות לריווח
- [ ] אין תאים ממוזגים
- [ ] אין מידע שמועבר בצבע מילוי בלבד
- [ ] ליחידות מקום בכותרת העמודה, לא בכל תא

## PDF

- [ ] המסמך **מתויג** — יוצא עם "Document structure tags for accessibility"
- [ ] לא נוצר דרך Print → PDF (מסלול זה מוחק את כל התגיות)
- [ ] מוגדר `/Lang`
- [ ] מוגדרת כותרת מסמך
- [ ] מופעל `DisplayDocTitle` — אחרת הקורא מכריז את שם הקובץ
- [ ] הגופנים מוטמעים
- [ ] העתקת פסקה בעברית מהמסמך מחזירה טקסט תקין
- [ ] עץ התגיות כולל H1-H6, L/LI, Table/TH/TD, Figure עם Alt
- [ ] תמונות דקורטיביות מסומנות כ-Artifact ולא כ-Figure
