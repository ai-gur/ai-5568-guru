# ספריית המקורות

מסמכי המקור שהפרויקט נשען עליהם. **זהו המקור הקנוני** — לא עותקים שנמצאים במקום אחר במחשב.

> ## 📄 המסמכים עצמם אינם בריפו
>
> הם קיימים **מקומית בלבד** בתיקייה הזו, ומזינים את הניתוח. הם אינם נדחפים ל-GitHub.
>
> **למה:** רוב המסמכים הם חקיקה ישראלית ואין בהם זכויות יוצרים — אבל **ת"י 5568 מציין "זכויות היוצרים שמורות למכון התקנים הישראלי"** באותו עמוד שבו הוא מציין "זמין לשימוש חופשי של הציבור". *זמין לשימוש* אינו *מותר להפצה מחדש*.
>
> **מה כן בריפו:** המסמך הזה — עם כתובת, תאריך פרסום, תאריך אחזור, `sha256` ורמת סמכות לכל מקור. זה מה שצריך כדי להוריד את המסמך ולהוכיח שקיבלת בדיוק את מה שאנחנו קראנו.
>
> **חריג אחד:** טופס הנציבות יושב ב-`sources/` **וכן** נדחף. הוא פורסם כדי שכל חייב יוריד וימלא אותו, ולכן הפצה מחדש תואמת את תכליתו — והוא הקובץ היחיד שנדרש כדי לשחזר את הקטלוג מ-clone נקי.

## ⚠️ שלוש רמות סמכות — לעולם לא לערבב

הכלל הזה מקביל להפרדה בין חלק 1/2/IL לבין MOB בקטלוג, ומופעל כאן על ספריית המקורות. **ערבוב בין הרמות הוא הדרך המהירה ביותר לאבד אמינות** מול הגוף שאנחנו שואפים שיפנה אלינו.

| רמה | משמעות | מותר לומר |
|---|---|---|
| ⚖️ **מחייב** | חוק, תקנות, תקן, טופס רשמי | "התקנות דורשות…" |
| 📋 **פרשנות רשמית** | עמדות ושאלות נפוצות של הנציבות | "עמדת הנציבות היא…" |
| 💡 **הנחיה מקצועית** | חומרי הדרכה, מדריכים | "מקובל לעשות…" / "מומלץ…" |

עמדת נציבות **אינה** תקנה. מדריך **אינו** תקן. כל ציטוט באתר הידע ובדוחות נושא את רמת הסמכות שלו.
